# 演示 V2：20 个业务问题验收清单

状态：2026-09-15，20题真实模型完整回归全部通过，结果与独立参考计算逐行、逐组及总计一致。冻结预期见 `evaluation/demo-v2-golden.json`，完整证据见 [验收报告](DEMO_V2_VALIDATION.md)。规则来自用户当前理解，后续按业务沟通调整。

固定快照暂定 2026-09-11。平台研发部、智能产品部为补充模拟部门；真实关系案例单独保留。每题注明身份，相关部门须处于该身份的演示授权范围。历史组织统一采用当前部门归属并向用户明示。

学校、学历、学位暂按宽表当前记录解释。为了演示毕业时间，暂将教育经历结束日期映射为毕业日期，种子数据保证一致并在配置里标注假设；真实接入需核对。院校985/211标签来自补充字典，属于对源字段的关联补充。工号始终保留前导零。

每题的实际数字和人员集合已基于固定300人合成数据，通过独立于待测SQL编译器的 Python 计算生成并冻结；这不代表业务方已审核口径。机器可读题单位于 `evaluation/demo-v2-cases.json`，含全部依赖字段、断言和对应验证报告。

## 每题需要保存的证据

- 数据种子、快照、源字段映射版本和授权策略版本。
- 当前身份、原始问题、前次问题 ID 与期望关键计划字段。
- 相关语义定义 ID、明确筛选条件、日期边界、人员范围或授权来源。
- 预期行集或聚合结果、实际结果、差异；空值、排序、分页、单位和四舍五入规则。
- 实际 LangGraph 节点及校验结论，定位第一个不满足断言的节点。
- 自然语言、数据表、图表与可视化核验入口的结果一致性。

已有测试继续保留。标准20题最终完整运行20/20；40条口语改写首次37/40，3项失败修复后定向复测3/3。权限、边界、多轮与历史由参数化测试和真实模型链路共同覆盖；实际执行清单及数量以 JUnit 报告为准。

强模型多次审核可作为离线辅助评审；模型一致同意不能代替独立计算和业务确认。可视化表单与聊天共用授权和执行边界，用于发现意图差异；计算正确性另用独立参考实现验证。
