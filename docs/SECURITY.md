# 授权与安全边界

## 身份与范围

演示提供5个身份，入口仅本机回环地址。身份切换本身是演示功能，不是企业认证。运行在demo以外模式时后端拒绝启动，正式上线需实现认证适配器。

| 身份 | 人员范围 | 薪酬 | 导出 |
|---|---|---|---|
| 公司负责人 | 自身及全层级下属，含可查询的历史离职记录 | 固定基本月薪汇总；禁止个人筛选与历史差分 | 允许基础获准结果，薪酬禁导出 |
| 研发负责人 | 自身及研发管理链 | 禁止 | 禁止 |
| 团队主管 | 自身及团队管理链 | 禁止 | 禁止 |
| HRBP | 分配的研发服务组织 | 禁止 | 允许基础获准结果 |
| 员工 | 仅本人 | 禁止 | 禁止 |

每个principal完整绑定角色、scope_mode、scope_root、敏感指标能力、导出能力和policy_version。不把不同授权的范围和字段进行笛卡尔组合。请求所选部门与此集合取交集，无法扩大范围。直属上级姓名若在查看范围之外则不返回。

## 执行防线

- 会话使用高熵随机令牌，应用库只保存其SHA-256摘要；HttpOnly、SameSite=Strict，8小时有效期。切换身份撤销旧会话。
- 写操作要求会话CSRF令牌；来源校验与TrustedHost保护阻止跨站和未知主机请求。演示切换端点因其作用而不要求已有会话，但仍受来源和回环部署约束。
- QueryPlan禁止额外字段，只允许固定枚举和结构；所有值绑定参数。模型无SQL执行工具与写业务库能力。
- 所有业务查询在只读连接执行，数据库authorizer允许的表/函数有限，执行最长2秒；明细1–100条、时间最长366天，模型单路推理、每分钟限额。
- 无跨用户结果缓存。看板仅存指标计划，重开按最新授权重查；其他身份无法取回或删除看板。
- 推理完成后刷新授权；跨身份追问ID被拒绝。前端切换身份清除结果和聊天，异步返回采用请求隔离。
- 明细不包含电话、证件、银行账户、薪资和绩效字段；模型只看语义目录与已授权组织名。
- 薪酬固定聚合少于5人隐藏，同时必要时隐藏另一个分组，避免用公司总计减去各组反推唯一隐藏分组。不开放任意人员过滤、关系过滤或历史薪资差分。此策略不是数学意义上的匿名保证。
- CSV导出单独鉴权，并对公式触发前缀做转义。API响应不缓存。React渲染文本，不执行模型生成的HTML或JavaScript。
- 审计不写入完整业务结果和SQL绑定值；记录动作、结果、指标、人员范围数量、策略版本和耗时。对话问题与结构化计划保存在应用库，仅供当前身份追问；生产应增加敏感信息清理与保留期限。

## 验证范围与生产要求

自动化覆盖匿名请求、身份伪造、CSRF、跨站、未知字段/SQL、越权组织、敏感指标、导出、其他人看板、目录过滤、撤权、数据库只读、模型不可用与跨身份追问。测试通过不代表完成渗透测试或企业合规评估。

生产接入前须完成：SSO账号与员工映射；HR批准的授权矩阵和组织数据源；正式数据库RLS/列权限及不绕过角色；HTTPS安全Cookie与完整CSP策略；集中审计/告警；限流共享存储；任务隔离；备份与恢复演练；企业日历和指标对账。不能将演示角色选择器通过公网代理当成登录系统。

## 调试记录访问控制

调试记录属于发起查询的身份，不能通过CEO角色横向读取其他主体的记录。读取时比较当前角色、范围、人员集合、功能权限与策略版本的授权指纹；变化后旧记录不可读取。SQL原始薪酬聚合不会写入节点，薪酬值只在结果保护后出现；常见凭据及模型显式内部推理被排除。调试仍可能含已授权员工信息，需按敏感应用数据处理。默认每身份最近50次运行，未完成运行暂不回收。完整技术元数据接口仅CEO演示身份可用，只展示结构，不读取会话、私人信息的值。详见 [DEBUGGING.md](DEBUGGING.md)。
