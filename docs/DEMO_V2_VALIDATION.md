## 权限与边界覆盖

自动化用例覆盖管理链58层、循环与孤立引用、HRBP自服务合法性、服务关系不作为管理边递归、继承范围去重；角色字段组、明细与导出开关；CSRF、跨来源请求、会话撤销、自由SQL拒绝与参数注入；历史跨身份、字段能力变化、权限继承关闭、主管边和HRBP边变化后的失效；模型调用期间发生权限变化时拒绝执行。

数值用例覆盖全量统计与分页分离、多部门并集、比例分母、未知学历、空年龄样本、半数向上舍入、无事件月份补零、未来合同日期、确认转正状态的隐含字段权限、按部门及月份下钻。

历史保存的是查询条件、结果版本与所有者。恢复时重新检查当前指纹；权限或数据变化后旧记录不可访问。页面每30秒同步指纹并清除失效显示，因此其他会话改权限到当前页面主动清除最长可能30秒；任何新请求都会实时重新鉴权。已经被用户看到或下载的数据无法通过撤权收回。

## 表格交互与性能含义

使用 AG Grid Community 36.1.0，保留成熟的列筛选、排序、列宽调整与分页体验。内置透视和聚合属于Enterprise功能；这里由受控后端提供最多两个分组、五个指标，再以表格和图表展示，不引入商业模块。依据：[AG Grid官方功能](https://www.ag-grid.com/react-data-grid/key-features/)、[官方仓库与许可](https://github.com/ag-grid/ag-grid)。

浏览器已验证：HR主管226位在职可见人员，学校筛选“清华”后为41人；独立对账覆盖41行；平台研发部其中9人，硕士及以上3人，占33.33%；下钻只显示3人的身份及学校、学历等必要字段。员工身份只返回冯基魁本人，且不显示合同及导出能力。配置管理员预览关闭HR主管HRBP继承，候选范围239人降至60人；验证只预览，现场策略保持版本1。

60次性能测试包含权限遍历、源数据及规则指纹、SQL、完整总计、分页与摘要，不含HTTP、浏览器和模型时间。该结果只适用于本机300人合成数据，不能推出真实PostgreSQL大表的吞吐、并发或延迟。正式接入需使用真实数量级压测、索引与执行计划检查，调整逐请求源指纹成本。

## 复现方式

```bash
npm run test:v2                    # V2确定性与模拟模型分支测试，临时状态
npm run test:model:v2              # 串行真实模型标准20题，临时状态
npm run test:paraphrases:v2        # 串行真实模型40条改写，临时状态
npm run test:performance:v2        # 60次串行查询，不调用模型
uv run python scripts/smoke_v2.py  # 已启动3000/8000时的HTTP检查
npm run typecheck
npm run lint
npm run build
npm run demo:production
```

全量旧版及V2回归应隔离 `HR_DATA_DIR`，避免旧版种子测试触碰现场演示库：

```bash
validation_dir=$(mktemp -d /tmp/hr-v2-validation.XXXXXX)
HR_DATA_DIR="$validation_dir" uv run python -m backend.hr.seed
HR_DATA_DIR="$validation_dir" uv run pytest -q --junitxml=reports/demo-v2-junit.xml
```

模型评测前及运行期间检查负载、可用内存和系统热状态，始终串行推理。运行记录保留各阶段检查；系统未记录热警告，没有可用的具体温度测量。构建限制线程并行。GitHub CI运行确定性测试、静态检查、构建与HTTP冒烟，真实LM Studio评测需在有该模型的本机另行运行。

## 演示与生产边界

本轮是能沟通配置、能解释和核验的本地演示。尚未接入真实PostgreSQL、SSO、数据库RLS、业务审批或生产监控；不支持任意SQL、任意跨库问题、历史组织还原，V2也没有考勤事实。当前学校仅表示宽表的一条教育记录，院校字典和毕业日期映射需与业务核实。未知分组及部分关系组合不提供一键下钻，页面明确提示。

所有交付结果、原始失败与复测引用汇总在 [机器可读验收报告](../reports/demo-v2-validation.json)。后续业务改口径或关系规则时，先更新版本与预期，再执行相关回归和真实模型问题集。
