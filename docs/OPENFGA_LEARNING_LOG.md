## 开发中发现并修复的问题

1. `self` 是 OpenFGA 保留关系名。真实服务拒绝模型后改为 owner，并说明它表示数据本人，与数据库表所有者不同。
2. 冷启动时批量关系检查触发默认3秒截止。保留“任何单项失败就整次拒绝”，调整服务端请求期限和并发上限，再跑完整真实服务回归。
3. 不能把 ListObjects 的截断结果当作完整名单。本课堂用固定候选全集逐批 Check，检查每项 correlation_id、布尔类型和错误。
4. 查询和同步是两条链路；仅换 OpenFGA 而不建立源版本/发布协议不能解决动态权限。当前方案刻意让未同步状态返回409。
