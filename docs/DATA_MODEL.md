# 数据模型、模拟生成与指标口径

## 时间与粒度约定

- 默认种子20260911，数据截止2026-09-11，时区Asia/Shanghai。默认480名员工，其中459名在职。
- 组织四级：公司 → 事业部/中心 → 部门 → 团队。组织与管理关系分开建模，HRBP服务范围不由其自身上级链决定。
- 员工一人一条；任职允许多条不重叠有效期记录，采用 `[valid_from, valid_to)`。离职日不计在职；当前任职保留离职人员的最后归属，供历史统计使用。
- 汇报闭包记录当前授权关系：自身depth=0，直属depth=1，间接depth>=2。历史分组读取业务发生时任职；当前可查人员集合仍按当前授权确定。这是演示策略，不是所有企业通用的历史权限规则。
- 考勤一人一工作日一条；完整保留正常、远程、请假、缺勤、缺卡，避免只有打卡记录时分母丢失。

## 模拟数据规则

使用Python标准库random.Random的独立种子，不依赖真实员工文件。研发、增长、交付、人力、财务采用不同人员权重；经理、普通员工、实习员工的职级与任期不同。包含调岗历史、约4.5%离职人员、不同用工类型、工作地点与审批状态。

邮箱使用保留域名`.example`，手机、证件、银行卡字段均为`SIM-`标识。薪酬金额为随机合成。统计分布用于演示，不表示行业平均值或实际企业劳动制度。

## 弹性考勤口径

用户给定：08:00–09:30弹性上班，18:00后下班，部分同事至22:00。

本演示补充假设：午休60分钟，净在岗要求480分钟，个人应离岗时间=`max(18:00, 上班打卡+9小时)`。

- 08:00上班，应离岗18:00；09:30上班，应离岗18:30。
- 09:30整不迟到，09:31迟到1分钟。
- 净在岗时长=`max(下班-上班-60分钟,0)`，缺卡不产生完整在岗时长。
- 早退分钟为个人应离岗时间减下班时间的正值。
- 晚离岗分钟为下班时间减个人应离岗时间的正值；不等于法定加班认定。
- 工作日加班申请单独生成，时长不超过观察到的晚离岗时长；仅`已批准`计入批准加班指标。
- 日历从年初开始，周一至周五为应出勤日，周末独立记录加班出勤，不接入真实法定节假日和调休安排；明确标记为模拟日历。
- 请假仅完整一天，不覆盖半天、小时假、跨午夜与跨时区班次。

固定边界样本：员工CC00052在截止日09:30–18:30；CC00053在09:31–22:00。生成器保证边界样本为完整打卡。

## 可复现生成

```bash
uv run python -m backend.hr.seed
uv run python -m backend.hr.seed --seed 42 --size 120
uv run python -m backend.hr.validate
```

默认保留应用库中的会话和看板。`--reset-app`明确重置应用数据，不在常规启动中使用。业务库先生成到临时文件，校验通过后原子替换。业务文件不提交Git。修改数据量时应使用对应种子和数据量重新评估性能。

生成器自动检查：外键、任职唯一与连续、无重叠、独立遍历的无环管理关系、组织层级、工作日与在离职范围、应出勤覆盖、打卡计算、请假关联、加班不超时、职级薪酬范围及全合成标记。随机数可重现不等于业务合理，规则校验与HR对口径确认仍必需。

## 真实宽表迁移

拿到100多字段宽表后，先确认主键/粒度与时间字段，再映射基础人员、任职、组织、考勤主题视图。不要求先修改源系统所有表。缺失历史、审批或应出勤日历时，对应指标显示不可用，不能从现状猜出历史或补造审批。

完整字段列表见 `DATA_DICTIONARY.md`，指标公式见 `semantic/catalog.json`，数据库约束见 `backend/hr/schema.sql`。

## 教育背景扩展（hr-data-2 / hr-metrics-1.1）

新增学校、教育经历和周末加班打卡三表。人员表六个最高教育快照字段便于档案展示，历史查询以教育经历表为准。最高学历按层级、毕业日期、记录ID排序，且毕业日期不能晚于业务事件日。学校筛选采用EXISTS，避免多条教育记录放大员工、考勤或加班事实。详见 `EDUCATION_ANALYTICS.md`。

教育和周末数据使用独立随机数序列；教育层级受入职年龄约束，教育经历在入职前完成，不重叠。部分合成博士入职事件特意安排在上季度，便于演示。非985/211样本用明确虚构学校，避免随意给真实学校贴标签。周末净在岗扣除休息，加班申请不超过独立打卡净时长，包含已批准/待审批/已拒绝样本。

部门分析按三级组织汇总团队；高层直属员工单列。任职历史过滤发生在入职日、离职前一日或考勤事件日，后来调岗不会改变早先的事件归属。授权仍使用当前身份范围。
