## 实际模型评测

`npm run test:model`明确调用LM Studio中的 `hr-qwen / Qwen3.8-27B-MLX`。20个案例包括13个常规问数、跨组织/敏感信息/伪装角色/写入请求，以及3个不支持条件案例。前一轮发现考勤明细误判为汇总和性别条件被忽略，已加确定性校验与对应API回归；第二轮20/20通过。

报告保留每个问题、期望的关键计划字段、实际计划、结果条数、状态和耗时。[原始模型报告](../reports/model-evaluation.json) 是场景验证，不是任意问法准确率100%的证明；其中一些拒绝由确定性校验完成，不能都算作模型理解成功。数值正确性主要由独立pytest基准验证，模型场景检查计划与授权范围。

## 查询性能

最近一次本地测量：串行p50 5.40ms、p95 8.30ms；并发8时p50 139.55ms、p95 178.11ms。见 [原始性能报告](../reports/performance.json)。当时本机同时有开发/模型工作负载，结果只用于本演示基线；真实数据规模、部署环境和网络需要重新压测。模型支持问题本轮约2–4秒，不含首次加载模型时间。

## 复跑与CI

小型业务改动先运行相关pytest文件和类型/lint；权限、指标、数据结构变更运行完整60项与23项不变量；模型提示或计划变更再运行真实模型场景。依赖或路由变更必须重新生产构建并检查实际浏览器。

`bash scripts/check.sh`是完整本地CI入口，执行前先停止已有演示服务以释放3000/8000端口。GitHub工作流已配置但尚未远程执行；真实模型评测在本机独立执行。`scripts/ci-smoke.sh`启动已编译版本执行HTTP验证，结束清理本次子进程。手动启动生产演示后，可运行 `uv run python scripts/smoke_http.py --model`。浏览器检查通过CUA实际操作完成，目前未配置云端浏览器自动化，不将手工交互记录称为自动化E2E。

依赖更新根据官方registry兼容范围与[React RSC安全公告](https://github.com/react/react/security/advisories/GHSA-wx67-qw84-cm4g)选择修复版本。最初发现的图像解析、RSC及工具链依赖漏洞已通过版本更新解决，未用忽略审计来消除报告。完整机器报告见 [dependency-audit.json](../reports/dependency-audit.json)。
