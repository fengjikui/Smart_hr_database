## 实际模型评测

`npm run test:model`明确调用LM Studio中的 `hr-qwen / Qwen3.8-27B-MLX`。40个案例包含原20项和新增20项教育、学校、占比、入离职、周末工时及权限场景。本轮初次38/40，通过案例中也存在学校条件需确定性校正的情况；两项失败为空计划默认执行、本人考勤未显式标注self。修复空计划校验和明确关系约束并添加回归后，第二轮40/40通过，其中8个场景记录了计划校正。

报告保留每个问题、期望的关键计划字段、原始模型计划、校正字段、最终计划、结果条数、状态和耗时。[原始模型报告](../reports/model-evaluation.json) 是场景验证，不是任意问法准确率100%的证明；其中一些拒绝由确定性校验完成，不能都算作模型理解成功。数值正确性主要由独立pytest基准验证，模型场景检查计划与授权范围。
