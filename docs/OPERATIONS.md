# 本地运行、发布与维护

## 服务组成

| 服务 | 地址 | 启动方式 |
|---|---|---|
| 前端与同源API代理 | `127.0.0.1:3000` | `npm run start`，事先build |
| HR API | `127.0.0.1:8000` | `npm run api` |
| 本地模型 | `127.0.0.1:1234/v1` | LM Studio |

推荐统一运行 `npm run demo:production`，或双击 `启动演示.command`。终端保持运行。单机仅一个API进程、一个模型推理并发；不启动多个uvicorn worker，否则限流和模型并发锁不再是全局约束。普通看板不使用模型。

启动脚本只加载已安装的 `qwen3.8-27b-mlx`，标识为 `hr-qwen`，上下文8192。不会自动下载数十GB模型。默认数据缺失时才生成；标准启动不重置应用库。演示运行中不执行seed或替换业务库。

## 常见问题

| 现象 | 处理 |
|---|---|
| 3000端口已有服务 | 先打开现有页面；若要更新，Ctrl+C停止原启动终端后重新启动。不要终止不明进程。 |
| 本地模型未连接 | 在LM Studio确认服务器1234运行、`lms ps`包含hr-qwen；启动器可补启动和加载。 |
| 模型繁忙429 | 同时只有一个推理；稍后重试。总览和已有看板不受影响。 |
| 模型超时/结构错误 | 页面明确报错；检查LM Studio资源、模型ID和上下文。不会回退为虚构回答。 |
| 更新后页面还是旧版本 | 停止服务，`npm run build`后重新生产启动；浏览器刷新。 |
| Cookie过期 | 刷新后进入演示身份初始化；切换所需身份。 |
| 指标版本不一致 | 停止服务，确保Git指标源和编译器同一版本，重启发布目录。旧版本看板会提示重建。 |
| npm镜像不支持audit | 使用 `npm audit --registry=https://registry.npmjs.org`，无需改全局registry。 |

环境变量模板见 `.env.example`。后端从进程环境读取；不会自动解析.env。不同模型服务的自定义URL/ID只用于分别手动启动的高级配置，统一启动器面向已验证的本机默认模型。前端只允许调用固定后端URL，不接受用户指定任意代理目标。

## 数据维护和备份

`data/hr.sqlite`是合成业务库，可以按记录的种子、规模和日期重建。`data/app.sqlite`包含看板、会话和问题，虽为演示也不应随意清空。使用 `--reset-app` 会清空应用数据，不是日常命令。

维护时先停止前后端，备份整个data目录（包含可能存在的WAL文件），再更新代码或重建业务数据。运行中备份应用库应使用SQLite Backup API，不能只复制主文件而漏掉WAL。生产需受控加密备份、权限、保留周期与恢复演练。

## 交付与CI/CD

`scripts/check.sh`按锁文件安装依赖、生成默认合成库、执行Ruff/pytest/类型/lint/构建。CI和Release工作流使用该项目的相同命令；标准CI不依赖27B模型，也不会假装完成真实模型评测。

`npm run release`要求Git工作树干净且已停止原演示，检查、构建及生产HTTP冒烟通过后以当前提交生成 `releases/chengguan-hr-<commit>.tar.gz`。包包含源码、锁文件和文档，不包含模型、node_modules、业务数据库或本机会话。

在目标内网模型主机解压，按README从干净检出步骤安装/生成/构建/启动。升级前保存旧提交对应源码包及应用数据备份，回滚需停服务、恢复兼容代码和备份。当前演示暂无跨版本数据库迁移框架，不能承诺任意新旧版本无损切换。

已提供 `.github/workflows/ci.yml` 和手动 `.github/workflows/release.yml`。没有远程仓库/服务器信息，因此本地已执行检查和打包，远程工作流与服务器自动部署尚未运行。正式CD需指定目标、凭据管理、迁移与回滚门禁；默认不会向外网发布。

## 安全运维边界

接口默认拒绝外部Host/Origin，但演示身份选择器允许本机访问者切换角色，不能把本机入口代理到公网或直接导入真实员工数据。正式接入要求见 [安全说明](SECURITY.md) 和 [生产接入路线](PRODUCTION_ROADMAP.md)。

记录请求数量、拒绝比例、查询耗时、模型耗时与失败原因，生产需要集中持久指标和告警；本机页面与测试报告不是生产监控系统。查询审计不记录结果行，但最小会话仍保存原始问题，真实上线须脱敏、限制访问并制定保留期。
